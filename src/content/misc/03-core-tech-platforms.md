> **说明：** 本文根据博睿康技术（上海）股份有限公司科创板上市申请《审核问询函之回复报告》（公开披露材料）整理，仅作学习笔记，不构成投资建议。完整原文见文末 [PDF](/files/neuracle-ipo-inquiry-reply-2026.pdf)。


问询材料开篇就点出三块可共用的核心平台：**微弱神经信号采集**、**信号解析**、**闭环反馈**；并补充非侵入侧的**系统集成**（高带宽无线、压缩、毫秒级时间对齐）。这一篇只谈平台「做什么」，具体产品放在后两篇。

## 1. 微弱神经信号采集

目标：在复杂使用环境下，把本来就很弱的脑电采得更稳、更可用。材料列举的手段包括：

- 前端感测链路优化  
- 信源级主动降噪  
- 全频域宽带采集  
- 阻抗检测、接触状态识别  
- 信号质量分级表征  
- 伪迹识别与级联降噪  

对 EEG 而言，材料还提到常见干扰：眼电（EOG）、肌电（EMG）、心电（ECG）传导、50/60 Hz 工频、以及电极接触不良等。采集平台要同时服务侵入与非侵入，所以「宽带 + 质量监测 + 级联降噪」会被反复强调。

## 2. 信号解析：从波形到意图／状态

材料把解析概括为三步：**预处理 → 特征提取 → 模式识别**，并加上在线适配。

| 环节 | 作用（材料表述） |
| --- | --- |
| 预处理 | 滤波、异常通道、基线校正等，压低工频、动作、肌电等非目标干扰 |
| 特征提取 | 时／频／时频／空域与脑网络特征，把连续波形变成可比较的指标 |
| 模式识别 | 用校准或训练数据建立特征与意图／状态的映射，再对新信号作判断 |
| 在线适配 | 按个体校准与使用中变化调整参数 |

应用侧归纳成两类：

1. **功能解码与状态评估**：在任务范式下识别运动意图、意识／认知／情绪相关特征或诱发响应，输出控制指令或量化指标。  
2. **临床辅助分析**：背景节律、阵发性异常、事件相关响应的检测与趋势展示，服务癫痫等场景的辅助诊断与长程监测。

材料中的应用类别表可简化为：

| 应用 | 要点 |
| --- | --- |
| 脑电特征检测 | 节律与 ERP；功率谱、短时傅里叶、小波等 |
| 运动意图识别 | 提取与运动意图相关的个体化频带与整体模式 |
| 异常活动判断 | 多尺度时频、尖波／高频振荡等；与 NEO-ONE ANS 闭环刺激相关 |
| 诱发响应监测 | VEP、AEP、运动相关电位等 |
| 临床场景显示 | 时频图、频带能量、预测指标与外设／视频同步 |

关于 **NEO-ONE SCI** 的运动意图解析，材料强调：需建立并稳定算法模型，并将「意图解析准确性」作为可衡量指标——具体数值与试验设计以原文披露为准，学习笔记不额外外推。

## 3. 闭环反馈：意图 ↔ 外设 ↔ 刺激

闭环模块在材料中包括（摘要）：

- 运动意图控制指令生成、外部执行设备联动  
- 反馈效果评估与参数优化  
- 异常脑电在线检测与分类  
- 闭环刺激时相识别与触发、刺激模式与时长调控  
- 癫痫检测与神经调控一体化  

在 SCI 产品语境下，闭环要同时覆盖：**意图 → 外设指令**、**异常脑电 → 刺激反馈**、**反馈效果 → 参数优化**。非侵入产品也会用到解析与部分闭环能力，但形态不同（更多是显示、评估与实验范式，而非植入刺激）。

## 4. 非侵入系统集成（预告）

材料单独点出：高带宽无线协议 + 智能压缩，服务多通道脑电与多模态生理信号高速传输；并为脑电帧与外部事件打精确时间戳，保证毫秒级同步。细节放在第 5 篇。
