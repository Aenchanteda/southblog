## 第一章：概论

### 1. 核心概念

**BCI（Brain–Computer Interface）**：绕过正常生理通路，使大脑直接与外部设备进行通讯。

### 2. 发展脉络

| 时间 | 事件 | 要点 |
|:----:|:-----|:-----|
| 1969 | Fetz：猕猴单神经元控制仪表 | 自动化控制视角——**能观性**是第一步，**能控性**是第二步 |
| 1973 | Vidal 提出 BCI 概念 | 概念正式命名 |
| 1986 | 群体向量解码 | 群体神经元方向信息的经典解码框架 |
| 2000s | BCI 实时控制 | 记录猴子上百神经元，实时解码控制机械臂 |
| 2010s | 临床概念验证 | 走向人体验证 |
| 2019 | 语言 BCI | 运动控制难有本质突破 → 转向语言；路径：语言意图 → 运动信号 → 合成语言 |
| 2021 | 双向闭环 BCI | 缓解纯视觉反馈的滞后；**体感反馈**很重要 |
| 2021 | 意念手写 | 高速率字符输出方向 |

### 3. BCI 的四个阶段

**神经界面** → **神经解码** → **神经控制** → **神经反馈**

#### 3.1 神经界面：多种神经信号

| 信号 | 侵入程度 | 备注 |
|:-----|:--------:|:-----|
| **Spikes** | 全侵入 | 单神经元动作电位（该细胞的**输出**）；需微电极贴近细胞 |
| **LFP** | 全侵入 | 局部场电位，更多反映附近群体的**突触电流（输入侧）** |
| **ECoG** | 半侵入 | 皮层表面 / 硬膜相关记录 |
| **EEG** | 非侵入 | 头皮记录 |

> **分类提示**  
> 若只分两类：把 **Spike 单独摘出**（细胞分辨率 vs 群体 / 场电位类信号）。

##### Spike 是什么？输入 / 输出为何不矛盾

- **Spike（锋电位）**：神经元发放的**动作电位**——短促的全或无电压脉冲，沿轴突传出。对「这一个神经元」来说，spike = 它的**输出**。
- **突触输入**：同一神经元树突上接收成千上万其他细胞的突触电流（EPSP / IPSP）。这些是它的**输入**；输入积分到阈值才会触发下一次 spike。
- 课上那句「单个神经元的输出 + 大量突触输入」指的是**同一细胞上的两个方向**，不是说 spike 既是输入又是输出：
  - 记录到的 **spike 波形 / 发放时刻** → 看的是输出；
  - **LFP / 场电位** 往往更贴近群体突触活动 → 更偏输入侧信息。
- ***Spike–field coherence***：spike 发放时刻与 LFP 相位 / 振荡的锁相关系，用来把「细胞输出」和「周围场（偏输入 / 群体）」对上。

#### 3.2 神经解码

- 基本映射：**neural activity → motor parameters**
- 直接电刺激可证实「小人模型」（皮层体感 / 运动拓扑），但 **神经 ↔ 运动** 的真实映射远更复杂  
  - 仅靠「纯手臂运动」难以落地：无法把复杂计算分解到精细控制单元上
- 两类解码思路：
  - **判别式**：直接学 \(p(\text{参数}\mid\text{神经})\) 或回归映射
  - **生成式**：建模联合 / 条件生成过程，再推断参数

#### 3.3 神经控制

| 类型 | 含义 |
|:-----|:-----|
| **同步式** | 系统规定时间窗；用户在窗内产生意图；神经时刻 \(t\) → 控制作用于 \(t\) |
| **异步式** | 用户自主发起；神经时刻 \(t\) → 控制作用于 \(t{+}1\)（或后续） |

#### 3.4 神经反馈

闭环中的反馈通道（视觉 / 体感等），用于校正意图与提升控制稳定性。

### 4. 当前瓶颈

1. **数据稀缺**：信号源单一、任务 / 场景单一、**模态**单一  
2. **算法唯象**：信号–参数映射固化，缺机理与可迁移表示  
3. **从零学习**：随机性大；算法难迁移、难泛化、难复用；初始化随机（动作目的的随机性）

### 5. 展望

基于**猕猴**建立基座模型：规避人体伦理约束；人–猴在相关神经机制上非常相近。

## 第二章：北脑一号

> **讲者 / 背景** · 张垒 · 北京脑所；技术栈含 EEG–fNIRS 等  
> **主题** · 脑机接口开发与转化

### 1. 应用定位与规范

BCI 目标：**监测 / 替代 / 康复 / 增强**。

建议阅读：药监相关口径、BCI 定义国家标准。

### 2. 代表性系统对比

#### WIMAGINE（EPFL）vs Neuralink（2020）

课上把欧洲脑–脊接口方案和 Neuralink 放在一起，对比体积、通道与侵入方式：

| | **WIMAGINE + EPFL（脑–脊接口）** | **Neuralink（2020）** |
|:---|:---|:---|
| 角色 | 头部采集 + 硬膜外脊髓电刺激 | 颅骨内无线全植入采集 |
| 侵入 | **半侵入**：硬膜外 ECoG（头上植 2 个 WIMAGINE） | **全植入** |
| 尺寸 | 直径约 **50 mm**，厚度约 **12 mm** | 直径约 **20 mm**（更小） |
| 通道 | 64 通道；为无线传输实际常用 **32** | **1024** 触点，在 **64** 根「微线」上 |
| 材料 / 审评 | — | **高分子材料**；课上强调「没发过国内审查」 |
| 连接 | 无线传输（通道数因此受限） | 无线数据传输 + **无线充电**；装置**嵌入颅骨** |
| 落地 | 体积大 → 植入患者很少 | 通道密度高、外形更紧凑 |

**WIMAGINE 补充**：硬膜外脊髓电刺激形成脑–脊闭环；受体积与无线带宽约束，临床例数少。

**Neuralink 补充**：高密度微线电极 + 全植入无线链路，是课上用来对照「半侵入大装置」的另一极。

#### 国内转化组织

北京市指导成立 **北京芯智达**：两条管线——**侵入** 与 **半侵入**。

### 3. 北脑一号：智能脑机系统

#### 3.1 系统组成

| 模块 | 内容 |
|:-----|:-----|
| 体内 | 体内机（线圈与天线、主机）、柔性颅内皮层电极 |
| 体外 | 体外机；USB / Wi‑Fi |
| 软件与应用 | 采集 / 解码软件；机械臂、光标、充气手套等控制 |

- **128 通道**同时采集  
- 硬膜外植入路径涉及：颅骨 – 硬脑膜 – 脑组织  
  - 脑组织侧信号往往更好，但**安全性通常不如硬膜外**

> **定位印象**  
> 全球首个百通道以上、高通量、**无线全植入的半侵入式** BCI 产品方向。

#### 3.2 关键技术点

- 低温升（控制在 **2°C 以内**，避免热损伤）
- 无线通信
- 高效宽距**无线供电**
- **超百通道馈通**
- 柔性电极：硬膜外 / 硬膜下
- 高集成度封装

##### 超百通道馈通（直觉）

钛合金外壳封闭电路 → 内外电气交流依赖馈通；陶瓷、法兰针等实现连接与气密；目标量级可达约 **1000 通道/cm²**。

馈通系统采用一层一层烧结的工艺。

#### 3.3 全产业链路径

1. 柔性电极  
2. 信号采集 + 无线传输与供电  
3. 高可靠连接 + 气密封装  
4. 热管理  
5. 整机 / 理化测试 / 型检 / 可靠性试验  
6. 动物实验 → 大动物实验 → 临床  

配套：**GMP** 生产车间。

### 4. 北脑一号应用与结果

#### 运动解码与康复（脑控）

- 小游戏、光标随机目标任务
- 捏玻璃珠
- 功能性电刺激（FES）康复训练

#### 脑–脊髓–外骨骼接口

- 脑控驱动：**脊髓电刺激 + 下肢外骨骼**
- 病例印象：胸腰段脊髓损伤致下肢瘫痪约 6 年，**ASIA-A** 完全损伤 → 出院约 5 个月后至 **C 级**

#### 北脑二号在研（动物）

- 猕猴；**512 通道**无线全植入
- 快速准确光标控制；信息率 **> 7 bps**

### 5. 发展趋势

1. 电极研发  
2. 算法升级  
3. 临床应用  
4. 整机系统  

**方向**：颅脑刺激的**双向闭环**（感知 + 刺激形成回路）。
